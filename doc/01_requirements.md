## 1. アプリ概要と目的 <!-- #1 -->

### アプリ名
**Life Stack**

### 概要
日々の予定・体重・食事を記録し、生活改善や振り返りを行う個人向け生活管理アプリ。  
一日の行動や栄養状態を見える化し、無理なく継続できる記録環境を目指す。

### 開発目的
- 日々の積み上げを見える化する
- 生活リズムを把握する
- 食生活を改善する
- 継続しやすい記録環境を作る

### ターゲットユーザー
- 自分自身（個人利用）
- 生活習慣を記録・改善したい人

## 2. 機能要件

### 2.1 スケジュール管理機能 <!-- #2 -->

| 項目 | 内容 |
|------|------|
| 目的 | 一日の行動を時間軸で把握する |
| 主な操作 | 予定の登録・編集・削除 |
| 主な表示 | タイムチャート（24時間）・カテゴリ別一覧 |

**機能詳細**
- 日付・タイトル・開始時間・終了時間・カテゴリを入力して予定を登録できる
- 登録した予定をタイムチャート形式で確認できる
- カテゴリを色分けして視覚的に区別できる
- 予定の編集・削除ができる

### 2.2 体重管理機能 <!-- #3 -->

| 項目 | 内容 |
|------|------|
| 目的 | 体重の推移を把握し、生活改善の指標にする |
| 主な操作 | 体重の日次記録 |
| 主な表示 | 折れ線グラフ（14日間）・平均値 |

**機能詳細**
- 日付・体重（kg）を入力して記録できる（1日1件）
- 過去14日間の体重推移をグラフで確認できる
- 14日間の平均体重を表示できる

### 2.3 食事管理機能 <!-- #4 -->

| 項目 | 内容 |
|------|------|
| 目的 | 食事内容と栄養摂取状況を把握する |
| 主な操作 | 食事の登録・編集・削除 |
| 主な表示 | 食事区分（朝・昼・夕・間食）別の一覧・栄養合計 |

**機能詳細**
- 食品名・食事区分・カロリー・タンパク質・脂質・糖質を入力して記録できる
- 朝食・昼食・夕食・間食ごとに一覧表示できる
- 一日の栄養合計（カロリー・PFC）を確認できる

### 2.4 栄養評価機能 <!-- #5 -->

| 項目 | 内容 |
|------|------|
| 目的 | 目標値との比較で食生活の過不足を把握する |
| 主な操作 | 目標値の設定 |
| 主な表示 | 摂取量 vs 目標値・過不足の表示 |

**機能詳細**
- カロリー・タンパク質・脂質・糖質の目標値を設定できる
- 一日の摂取量と目標値を比較表示できる
- 過剰・不足を視覚的に確認できる（プログレスバー等）

## 3. 入力・表示仕様

### 3.1 スケジュール管理 - 入力仕様 <!-- #10 -->

| フィールド | 型 | 必須 | バリデーション |
|-----------|-----|------|----------------|
| 日付 | date | ✅ | 有効な日付 |
| タイトル | text | ✅ | 1〜100文字 |
| カテゴリ | select | ✅ | 登録済みカテゴリから選択 |
| 開始時間 | time | ✅ | HH:MM 形式 |
| 終了時間 | time | ✅ | HH:MM 形式、開始時間より後 |
| メモ | textarea | ❌ | 最大500文字 |

**カテゴリ（初期データ）**

| カテゴリ名 | カラー |
|-----------|--------|
| 仕事 | `#4A6CF7` |
| 運動 | `#22C55E` |
| 食事 | `#F59E0B` |
| 休憩 | `#8B5CF6` |
| その他 | `#6B7280` |

### 3.2 体重管理 - 表示仕様 <!-- #11 -->

| 表示項目 | 仕様 |
|----------|------|
| グラフ期間 | 直近14日間（データがない日はスキップ） |
| グラフ種別 | 折れ線グラフ |
| Y軸 | 記録された最小値 −1kg 〜 最大値 +1kg |
| 平均値 | 14日間の平均（小数点第1位） |
| 最新値 | 最新の記録を大きく表示 |
| 体重単位 | kg（小数点第1位まで入力可） |

### 3.3 食事管理 - 入力仕様 <!-- #12 -->

| フィールド | 型 | 必須 | バリデーション |
|-----------|-----|------|----------------|
| 日付 | date | ✅ | 有効な日付 |
| 食事区分 | select | ✅ | breakfast / lunch / dinner / snack |
| 食品名 | text | ✅ | 1〜100文字 |
| カロリー | number | ✅ | 0〜9999 kcal（整数） |
| タンパク質 | number | ✅ | 0〜999.9 g（小数点第1位） |
| 脂質 | number | ✅ | 0〜999.9 g（小数点第1位） |
| 糖質 | number | ✅ | 0〜999.9 g（小数点第1位） |

> **Note**: DB カラム名・API は `carbs_g`（国際標準の `carbs` に合わせる）、UI 表示は「糖質」で統一する。
| メモ | textarea | ❌ | 最大500文字 |

**食事区分の表示名**

| 値 | 表示名 | 時間帯（目安） |
|----|--------|----------------|
| breakfast | 朝食 | 〜10:00 |
| lunch | 昼食 | 10:00〜15:00 |
| dinner | 夕食 | 15:00〜21:00 |
| snack | 間食 | 随時 |

### 3.4 栄養評価 - 判定仕様 <!-- #13 -->

**目標値との比較ロジック**

| 達成率 | 判定 | 表示カラー |
|--------|------|-----------|
| 90%〜110% | 適正 | 緑 `#22C55E` |
| 110%超 | 過剰 | 赤 `#EF4444` |
| 90%未満 | 不足 | オレンジ `#F59E0B` |

**デフォルト目標値（設定変更可）**

| 栄養素 | 目標値 |
|--------|--------|
| カロリー | 2000 kcal |
| タンパク質 | 60 g |
| 脂質 | 65 g |
| 糖質 | 260 g |

## 4. MVP 機能一覧 <!-- #8 -->

### MVP に含む機能

優先度は詰まったときの削減判断に使う。Medium 以下は実装順序を後回しにしてよい。

| 優先度 | 機能 | 説明 |
|--------|------|------|
| 🔴 High | 体重入力 | 日次体重を kg 単位で記録 |
| 🔴 High | 食事入力 | 食品名・カロリー・PFC を記録 |
| 🔴 High | 栄養合計表示 | 一日の栄養合計と目標値比較 |
| 🟡 Medium | スケジュール登録 | 予定を日付・時間・カテゴリ付きで登録 |
| 🟡 Medium | 体重グラフ表示 | 過去14日間の折れ線グラフ |
| 🟢 Low | タイムチャート表示 | 24時間のタイムライン表示 |

### MVP に含まない機能（将来対応）

| 機能 | 理由 |
|------|------|
| 睡眠管理 | スコープ外（将来追加） |
| AI による生活分析 | 外部 API 連携が必要 |
| スマホ対応（PWA） | MVP 後に対応 |
| カレンダー連携 | 外部 API 連携が必要 |
| CSV エクスポート | MVP 後に対応 |

## 7. 使用技術候補 <!-- #14 -->

| カテゴリ | 技術 | 選定理由 |
|----------|------|----------|
| フレームワーク | Next.js (App Router) | React + SSR + ルーティングを一括管理 |
| 言語 | TypeScript | 型安全・IDE サポート |
| DB | SQLite | ローカル保存・セットアップ不要 |
| ORM | Prisma | TypeScript 親和性・マイグレーション管理 |
| スタイリング | Tailwind CSS | ユーティリティクラスで高速 UI 構築 |
| グラフ | Recharts | React 向け・カスタマイズ容易 |
